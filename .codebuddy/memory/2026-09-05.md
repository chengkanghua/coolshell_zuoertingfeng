## HTML img 图片不显示根因与修复（my-project）
- 现象：md 内 `<img src="./img/...">` 在 mkdocs serve 404。
- 根因：mkdocs `use_directory_urls:true` 使页面 URL 为 `/000-开篇词…/`(目录式)；原始 HTML `<img>` 的相对 src 不会被 mkdocs 重写(仅 markdown 语法链接会被重写)，浏览器以页面目录为基准解析到 `/000-…/img/...` 而真实图片在 `/img/...`，故 404。
- 修复：全库 `<img>` HTML 标签仅 2 处（000-开篇词-….md、README.md），已改为 markdown 语法 `![alt](相对路径)`，渲染后 mkdocs 自动重写为 `../img/...` 正确路径。
- 无现成插件可事后修正 HTML 内相对 src；可选方案：`use_directory_urls:false`(改变全站 URL 风格) 或自写 on_page_markdown 插件 / 一次性正则转 markdown(html img→![alt](src))。
- 遗留批量问题：229 条 build warning 是文档间旧链接失效（目录文件引用 `84-xxx.md` 而实际文件名 `084-xxx.md`，编号缺前导零），与图片无关。
